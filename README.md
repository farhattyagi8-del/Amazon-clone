# 📦Amazon-web clones


A fully responsive **Amazon.in** frontend clone built using **only HTML and CSS**.


## ✨ Features

- Fully Responsive Design (Mobile + Tablet + Desktop)
- Modern & Clean UI similar to Amazon.in
- Hover Effects & Smooth Transitions
- Product Grid Layout
- Navbar with Search Bar
- Cart Sidebar
- Hero Banner with Sliding Effect (CSS)
- Footer with Multiple Sections
- Star Rating System
- Deal of the Day / Lightning Deals Section

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Flexbox & Grid)
- No Framework Used (Pure HTML & CSS)
